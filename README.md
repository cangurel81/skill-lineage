# skill-lineage

[![test](https://github.com/cangurel81/skill-lineage/actions/workflows/test.yml/badge.svg)](https://github.com/cangurel81/skill-lineage/actions/workflows/test.yml)

Deterministic duplicate, variant and name-conflict detection for large
`SKILL.md` catalogs. Standard library only, Python 3.9+, MIT licensed.

It answers one question: **given a folder of skills, which files are copies,
which are variants, and which two skills are fighting over the same name — and
which copy should be kept?**

It is plan-only. It never deletes, moves or writes to a catalog.

## Why

Skill directories accumulate copies from downloads, translations, vendored
bundles and local forks. A plain file hash finds exact copies but misses three
common cases:

- the same skill with reordered frontmatter or normalized line endings;
- a translated copy that is clearly the same skill but not byte-identical;
- two different skills that both declare `name: browser` and collide.

`skill-lineage` reports all four cases with an explainable canonical choice.

## Install

No dependencies. Clone and run:

```sh
python scripts/skill-lineage.py scan <root> --json
```

Or use it as a module:

```sh
python -m skill_lineage scan <root> --json
```

## Commands

| Command | Output |
|---|---|
| `scan` | Summary counts for exact / normalized duplicates, variants, conflicts and removal candidates. |
| `plan` | Review-only `remove-candidate` actions with `duplicate_of`, confidence and `requires_review`. |
| `report` | Markdown report listing each group's keep decision and candidates. |

A root may be a `SKILL.md` file, a skill directory or a whole catalog tree.
Pass several roots to compare them in one pass.

### Options

| Flag | Default | Meaning |
|---|---|---|
| `--json` | off | Emit one machine-readable JSON object. |
| `--near` | `0.85` | Token Jaccard threshold used to call a same-name pair a variant. |
| `--fail-on` | `never` | Exit `1` on `any` finding, on `conflict` only, or `never`. |

Exit codes: `0` clean or completed, `1` findings matched `--fail-on`, `2` bad
input (invalid `--near`, no roots with skills, unreadable path).

## JSON shape

```json
{
  "tool": "skill-lineage",
  "version": "1.0.0",
  "command": "scan",
  "roots": ["..."],
  "near_threshold": 0.85,
  "analysis": {
    "summary": {
      "skills": 0,
      "exact_groups": 0,
      "exact_copies": 0,
      "normalized_groups": 0,
      "normalized_copies": 0,
      "name_conflicts": 0,
      "name_variants": 0,
      "remove_candidates": 0
    },
    "exact": [],
    "normalized": [],
    "conflicts": [],
    "variants": []
  },
  "exit_code": 0
}
```

A `plan` payload replaces `analysis` with:

```json
{
  "dry_run": true,
  "destructive": false,
  "actions": [
    {
      "action": "remove-candidate",
      "path": "...",
      "duplicate_of": "...",
      "confidence": "exact",
      "requires_review": false
    }
  ],
  "summary": {}
}
```

## How canonical selection works

Each group ranks its members by a transparent score:

1. Has both `name` and `description` (+3).
2. Description is at least 25 characters (+2).
3. Body is not a CJK translation (+2).
4. Lives in a preferred root label (`local`, `claude`, `opencode`) (+1).
5. Vendor roots are penalized (-1).
6. Oldest file in the group gets a tie-break point (+1).

Ties break on shortest path, then path string, then discovery index. The report
prints the reason string for the winner, so a human can override it.

Exact copies are marked `requires_review: false`. Normalized duplicates,
name variants and name conflicts are always `requires_review: true`.

## Catalog audit (measured)

Measured with `scan` against the local skill catalogs on 19.11.2026. Numbers are
generated by this tool, not estimated:

| Root | Skills | Exact groups | Exact copies | Name conflicts | Name variants | Removal candidates |
|---|---:|---:|---:|---:|---:|---:|
| `~/.config/opencode/vendor` | 11,217 | 3,089 | 5,972 | 64 | 552 | 8,005 |
| `~/.claude/skills` | 18 | 0 | 0 | 0 | 0 | 0 |
| `~/.config/opencode/local-skills` | 3 | 0 | 0 | 0 | 0 | 0 |
| `~/.config/opencode/claude-seo/skills` | 26 | 0 | 0 | 0 | 0 | 0 |
| `~/.config/opencode/skills` | 1 | 0 | 0 | 0 | 0 | 0 |
| **All roots in one run** | **11,265** | **3,091** | **5,974** | **64** | **580** | **8,093** |

The combined run also found 1 normalized-duplicate group (4 copies). Comparing
all roots together exposed 2 extra exact groups and 28 extra name variants that
no single-root scan could see — the main reason to pass several roots at once.

Whole catalog scan time on this machine: about 115 seconds for 11,265 files.


## CI gate

```yaml
- name: Block name collisions
  run: python scripts/skill-lineage.py scan skills --fail-on conflict --json
```

Use `--fail-on any` if you also want to block duplicates and variants.

## Tests

```sh
python -m unittest discover -s test -v
python -m compileall -q skill_lineage scripts
```
